KNOBOLOGY / LYRAHOME DEPLOY KIT
===============================

STEP 1.  Create a Cloudflare API token:
         dash.cloudflare.com  ->  My Profile  ->  API Tokens  ->  Create Token
         Template: "Edit Cloudflare Workers"
         Account Resources: the knobology account
         Create -> copy the value (shown ONCE)

STEP 2.  Save it as a plain text file named exactly:  cf-root-token.txt
         in THIS folder. Nothing else in the file.

STEP 3.  Run:   python deploy-stream.py

That is all. The script checks the worker bytes first and aborts on any mismatch,
PUTs it, waits 25 seconds, then runs eight live checks and prints PASS/FAIL per
line. Eight PASS = the site is fixed.
